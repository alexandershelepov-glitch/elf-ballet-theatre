# Детский театр балета «Эльф» — сайт

Официальный сайт Детского театра балета «Эльф» (Москва, с 1992 года).

**Продакшен:** https://elfballet.ru

## О сайте

Статический сайт на чистом HTML/CSS/JS без фреймворков и сборки.
Хостинг — GitHub Pages, собственный домен подключён через `CNAME`.

## Структура

```
├── index.html                      # Главная страница
├── styles.css                      # Все стили (цвета и сетка — в CSS-переменных)
├── script.js                       # Мобильное меню (бургер)
├── horeografiya-dlya-detej/        # Посадочная: хореография 3,5–7 лет
├── klassicheskij-tanec-dlya-detej/ # Посадочная: классический танец 8–18 лет
├── plastika-dlya-detej/            # Посадочная: пластика 8–18 лет
├── teatralnaya-studiya-dlya-detej/ # Посадочная: театральная студия 3–18 лет
├── assets/images/                  # Изображения
├── robots.txt                      # Правила для поисковых роботов
├── sitemap.xml                     # Карта сайта
└── CNAME                           # Домен elfballet.ru для GitHub Pages
```

## Локальный запуск

Сборка не требуется. Достаточно открыть `index.html` в браузере
или поднять простой статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Деплой

Сайт публикуется автоматически: любой коммит в ветку `main`
обновляет https://elfballet.ru через GitHub Pages.

## Правки контента

- **Тексты и страницы** — прямо в соответствующих `index.html`.
- **Фотографии** — заменить файл в `assets/images/` (сохраняя имя)
  или добавить новый и поправить путь в HTML/CSS.
- **Цвета, шрифты, отступы** — переменные в начале `styles.css` (`:root`).
- **Новая страница в sitemap** — не забудьте добавить её в `sitemap.xml`.
